Get started

From install to your first conversation on IRCnet, in eight steps. Every command you type in erssi also has its own page in /help.

Install

Run this on your shell account, no root needed. The installer checks the release signature and the package before it changes anything. On Debian 12 and 13, Ubuntu 24.04 and FreeBSD 14 and 15 it installs a ready-made binary in seconds; elsewhere it builds erssi from source.

$ curl -fsSL https://raw.githubusercontent.com/y-o-o-z/erssi/main/shellter-install.sh | sh

At the end the installer tells you where erssi is. If it says ~/.local/bin is not in your PATH, add this to ~/.profile and log in again:

export PATH="$HOME/.local/bin:$PATH"

Start it in tmux

In tmux erssi keeps running when you log out, and you come back to the same session, from your phone too.

$ tmux new -s irc erssi        # first start
$ tmux attach -t irc           # back to the session

Detach with Ctrl-b, then d. On the first start erssi asks for a network, a nick, a SASL account, a theme, and whether to check for new releases once a day. Enter keeps the value in brackets, and erssi --setup asks again.

Connect to IRCnet

If you picked a network on the first start, erssi connects by itself. Otherwise:

/connect IRCnet
/join #shellter

/nick changes your nick, and /keepnick takes yours back the moment it is free. Private messages and highlights also go to the Mentions window, so nothing slips past.

Windows, panels and the mouse

Every channel and every conversation is a window of its own. The window list is in the left panel, the channel's nicks in the right one.

  • Alt-1…Alt-0 go to windows 1–10, Ctrl-n and Ctrl-p to the next and previous one.
  • Click a window in the list to switch to it, click a nick to open a conversation, scroll the text with the mouse wheel.
  • Drag sideways in the chat to go to the neighbouring window (/set mouse_gestures off turns it off).
  • /window close closes a window, /set sidepanel_left off and /set sidepanel_right off hide the panels.

erssi handles the mouse itself, so to select text hold Shift (Option or Fn on macOS) while you drag. Open a link by clicking with Ctrl, Ctrl-Shift or Cmd, depending on the terminal.

Encrypt a conversation

End-to-end encryption is built in and works with repartee and its scripts. Both sides turn it on, in a query or a channel:

/e2e on

When the other person asks for your key, erssi says so in the window. Accept them; from then on erssi answers their later requests by itself:

/e2e accept

/e2e status shows your key's fingerprint, /e2e list the people in the window. Encryption protects what you write, not who talks to whom.

Update from inside erssi

When a new release is out, erssi says so briefly in the Notices window. Install it in the background while you chat, then load it into the running erssi:

/update install
/upgrade

/upgrade keeps your windows and channels; TLS connections reconnect once. /update install -upgrade does both steps, and /update shows when releases were last checked and what was found. From a shell, erssi --update does the same.

Turn on backups

One backup holds your config, themes, scripts, E2E keys and passwords (not the IRC logs). This makes one every day and keeps the last seven:

/set backup_auto daily
/backup now   # a backup right away

From a shell, for example when moving to another box:

$ erssi --backup ~/erssi.tar.gz
$ erssi --restore ~/erssi.tar.gz

A backup holds your private keys and passwords, so it is mode 0600. Keep it to yourself.

Light or dark

The shellter theme is for dark terminals, shellter-light for light ones. The change shows at once, and /save keeps it:

/set theme shellter-light
/save

When something does not work

/help covers every command, for example /help e2e or /help update. If the install fails, see When the install fails. Ask on #shellter on IRCnet, or report a problem.
