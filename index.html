erssi Shellter Edition: the modern irssi, tuned for IRCnet.

What an IRCnet user sets up by hand is already built in. It keeps your nick, gathers your mentions, encrypts what you ask it to and updates itself from signed releases. No root needed, on Linux or FreeBSD.

$ curl -fsSL https://raw.githubusercontent.com/y-o-o-z/erssi/main/shellter-install.sh | sh

Installs into ~/.local/opt/erssi and links ~/.local/bin/erssi. What it does · How to check it

==> ~erssi/.plan <==What 2026.10.6 changes

Fixes from a full review of the code, each with a test that failed before the fix. Released on 25 October 2026, after CI passed 6 of 6 and the packages were built and tested on Debian 13 and FreeBSD 14.

  • screen

    Nothing from the network can send control characters to your terminal any more, on any terminal type: C0, DEL and C1 are drawn as ?, so a channel name cannot set your clipboard or window title. A focus report split over a slow ssh link is still read as one.

  • install

    --uninstall removes only what the installer put there; libraries, headers and man pages of other software in the same prefix stay, and it names what it left. A lock left by a killed installer or a reboot is taken over safely. man erssi works for an install in your home.

  • fe-web

    New connections are limited per peer before TLS starts. The web nick list follows the server, so /ignore leaves no ghosts. Text sent to the browser is always valid UTF‑8 and follows /recode. New certificates get a random serial, the extensions browsers expect and a lifetime of 825 days.

  • e2e

    Key requests have a budget per sender, the keyring is cached instead of being read again for every stranger's notice, and freed plaintext is wiped. The security notes now say plainly that a server can drop or reorder the parts of a long message.

  • core

    /upgrade checks that it can write the session file before it hands anything over, and a failed /upgrade sends nothing twice and keeps your windows. Keepnick no longer prints MONITOR replies twice.

  • image preview

    A preview goes with its line after /clear, downloads stay .part files until they are complete, page pictures (og:image) are found and resolved properly, and downloading no longer makes typing lag.

  • build

    A manual page of its own, erssi(1). The GLib minimum is stated truthfully (2.70), and the image decoder has a fuzz target.

What the installer does on each system
debian13 · freebsd14Installs the release's ready-made binary (amd64) once the signature on its SHA256SUMS, its checksum and its manifest check out. Takes seconds.
other systemsBuilds the newest signed release from source and runs the test suite. Needs GLib 2.70 or newer; missing packages are named, with the command to give your administrator.
--rollbackReleases sit side by side, and current switches back to the previous one in one step.
--uninstallRemoves only what the installer put there, and never ~/.erssi.

All options, and what the installer verifies

  1. Start it inside tmux

    The session survives logging out. The first start asks for a network, a nick and the theme, then connects.

    tmux new -s irc erssi

  2. Update when a release comes out

    erssi --check-update   # is a newer release available?
erssi --update         # install it

  3. Then /upgrade in the running erssi

    It loads the new version and keeps your windows and channels. Connections over TLS cannot be handed to the new process, so they reconnect once.

Check the tag by hand

In a clone of the repository, with gpg switched off so that only this SSH key counts:

git -c gpg.program=false -c gpg.openpgp.program=false \
    -c gpg.x509.program=false -c gpg.format=ssh \
    -c gpg.ssh.allowedSignersFile=utils/allowed_signers \
    verify-tag shellter-v2026.10.6

It must report a good signature with the fingerprint above. Compare that fingerprint with one you got another way, for example by asking on #shellter. The steps for a package are in install.md.

==> ~erssi/features/ <==What an IRCnet user would otherwise script

Everything erssi brings stays: side panels, mouse support, 24-bit colour, image preview, a web frontend and irssi's Perl scripts. This edition adds the rest, and every command has a page in /help.

  • -rwxr-xr-xkeepnickYour nick, kept. /keepnick takes it back the moment it is free: through MONITOR where the server offers it, otherwise ISON, and at once when the holder quits or changes nick in a channel you share.
  • -rwxr-xr-xe2eEnd-to-end encryption. RPE2E natively, wire-compatible with repartee and its WeeChat and irssi scripts: XChaCha20-Poly1305 with per-sender keys, given only to people you accept. It protects what you say, not who talks to whom or when, and it has no forward secrecy.
  • -rwxr-xr-xmentionsMentions in one place. Private messages, notices from people and hilights in one window and in a log only you can read, with a desktop notification through the terminal, also inside tmux.
  • -rwxr-xr-xsearchSearch your logs. /search looks through the logs of the channel you are in, or of every network with -all, in a separate process, so erssi carries on while it searches.
  • -rwxr-xr-xlayoutWindows that stay put. Side panels with your windows and the channel's nicks by rank, every row of split windows with its own nick list, and layouts that come back after a restart exactly as saved.
  • -rw-r--r--shellter.themeOne column for every line. Messages, events, server replies and WHOIS share one column and one separator, as in the picture above; shellter-light does the same for light terminals.
  • -rwxr-xr-xfe-webA browser when you need one. The same session in a web client such as NexusIRC. On a shared box it listens on a Unix socket only you can open.
  • -rwxr-xr-xscriptsYour irssi scripts. irssi Perl scripts run as they are, and scripts that ask for irssi 1.4.5 or newer load. trackbar.pl comes with it.
